Business Success Stories - Driver Monitoring System | Sasken

Written by Admin | Dec 25, 2019 5:00:00 AM

Scope: Concept to Production Ready solution integrating Lidar and Camera (inward facing) for Driver Drowsiness Detection

Solution:

  • Concept formulation, competitive market analysis
  • Selection of hardware platform based on performance analysis and peripheral interfacing
  • Porting, optimization and development of vision
    • Deep learning models developed using Keras library
    • Developed Python scripts for DDD post processing
  • Performance analysis of vision-based algorithms
    • Driver Drowsiness Detection is signalled via audio alerts for events like Blinks, Head Tilt, Yawning, etc.
    • Support for infrared sensors for low light conditions
    • Drive Record
  • Test environment on PC platform to simulate the road scenario as seen by the camera
  • System integration

Impact:

Complete driver monitoring system available on Nvidia platform
