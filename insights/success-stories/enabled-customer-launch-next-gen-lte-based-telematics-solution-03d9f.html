Success Stories - Next-gen LTE-based NAD Software | Sasken

Written by Admin | Dec 3, 2018 5:00:00 AM

Scope: Customer was developing next-gen LTE-based telematics solution by re-using the existing vehicle interface module and developing the NAD software from scratch. They were looking to partner with a vendor with extensive expertise in NAD software development.

Solution: 

  • Sasken deployed team comprising of architects in various domains like Modem, Telematics Middleware to come up with overall system architecture and interfaces.
  • Supported in FOTA integration and USB module maintenance for development of advanced TCU
  • Designed and developed TCU modem features such as Pre-AC, Diagnostics (UDS/OBD2), Remote AC Setting, Remote Engine Start, CAN monitor, vehicle health report, HeartBeat monitor, Wi-Fi
  • Implemented signal handler between embedded data system and telematics re-flash app, common functions for GASoline vehicles, data logger for error recording into flash memory
  • TCU test automation for E-call, Remote Door Lock/Unlock, Remote horn, Remote Light ON/OFF, Stolen Vehicle Tracking, Intrusion Alert and Car Finder
  • Designed a GUI to simulate Navigational Head Unit
  • Automated the relay to test and simulate E-call trigger, E1 debugger, TCU Power and Ignition

Impact:

Leveraging its extensive experience in 2G/3G/LTE, telematics technologies, Sasken enabled the customer to execute the project.
