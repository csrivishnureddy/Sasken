Business Success Stories - Testing of Telematics Apps | Sasken

Written by Admin | Aug 17, 2018 4:00:00 AM

Scope

Automate end-to-end testing of data flows and presentation for Telematics applications

Solution

  • Authored 500+ automation test scripts in robot framework leveraging keyword-driven testing approach
  • Created new higher-level keywords to invoke robot framework and custom libraries for data validation
  • Leveraged test bench from dSPACE to provide input to Telematics ECM
  • Utilized APIs from Selenium WebDriver to simulate user interaction on application UI
  • Automated functional validation at multiple touchpoints: On-board Telematics gateway, subscription portals, application UI etc.

Impact

  • Accurate representation of real-world use cases with key-word driven test cases
  • Reduced system testing time by 70% in a distributed system set-up
  • Optimized test case development time by reusing generic keywords
  • Enhanced reporting of test results leveraging built-in robot framework test suite
