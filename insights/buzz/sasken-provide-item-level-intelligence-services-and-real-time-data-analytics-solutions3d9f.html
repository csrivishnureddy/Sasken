Real-time Data Analytics Solutions in Fashion Retail | Sasken

Written by Admin | Apr 1, 2017 4:00:00 AM

Sasken will be involved in developing a pilot catwalk application in iOS and Android for a leading European independent software vendor (ISV). The application will work in conjunction with an RFID sleeve to enable the customer's solutions across retail stores. The application features include stock taking, article information, and inventory refill. Sasken proposed to develop the application using Xamarin - a cross-platform application development engine. As Xamarin's premier consulting partner, Sasken will be able to deliver the iOS and Android applications in a shorter time frame and allow better usability and maintenance in comparison to native applications.
