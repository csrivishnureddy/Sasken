Enhanced User Experience: Touch-screen-based GUI

Written by Admin | Jan 20, 2020 5:00:00 AM

Scope: Customer was developing a next-gen industrial kettle and was faced with the challenge of making a GUI which could manage the dramatic increase in the number of data points, enhance user experience, and recognize deviances in the food production quickly and effectively with real-time KPI updates.

Solution:

  • Developed UI for Kettle Machines
  • QT UI embedded Linux on customer’s proprietary platform
  • Designed for different user roles:
    • Cook has basic privileges to maintain recipes
    • Admin can change the language
    • Maintenance personnel have privileges to change security limits i.e. maximum water flow and temperature
  • Enabled software upgrade via USB and multilingual  UI with support for 12 languages
  • Enabled enhanced security features
  • Intuitive Touch Screen-based GUI
  • Memory Management: Ability to upload and save recipes in memory
  • Software Maintenance

Impact:

  • Increased the number of screens by 50%
  • Better visibility of machine KPIs with real-time data updates
  • Real-time temperature control
  • Easy programming
