Bluetooth Solution for a North American Tier-1

Written by Admin | Dec 24, 2019 5:00:00 AM

Scope:

  • Customer was looking for development and maintenance of various Bluetooth components for Automotive IVI systems.
  • Technologies: BT (2.0, 2.1+EDR, 3.0, 4.0), TI WiLink chipset, CSR chipset; OS: MQX (RTOS), Linux, Windows

Solution:

  • Provided BT connectivity integration in Automotive Infotainment products over iAnywhere BT stack
  • Responsibilities included development and maintenance of advance feature enhancements like BT profiles, demo applications for trade and customer shows:
    • PAN profile demo: Realize VPN using the PAN profile on windows environment
    • PBAP Download Speed: Phonebook download from Smartphone to Carkit optimization based on folder versions
    • Implemented BCSP logging mechanism in FTS file format
    • Adaptation to new HFP profile versions
  • Tools: Coverity and VectorCast for code quality maintenance
  • Configuration Management: IBM Rational Team Concert

Impact:

Sasken’s expertise enabled customer to launch the solution within the deadlines specified by the OEM
