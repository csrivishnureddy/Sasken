Success Stories - Reduced Time-to-Market by 30% | Sasken

Written by Admin | Jul 21, 2020 4:00:00 AM

Scope:

Customer was looking for a partner to support them in designing and developing instrument cluster applications on a QNX platform and cluster

Solution:

  • Sasken was involved in supporting the customer with the following:
    • Design and development of Instrument Panel Cluster Applications and HMI for Telltales, Backlight illumination/Dimming, Warnings, Secured Configurations, Traffic Jam Assist, Off-road/Off-road IoD, Vehicle Pitch, Roll and Steering Angle, Trailer, Driver/Rear Seat Belt Monitoring, etc.
    • Applications developed according to Hardware Defined Software Requirement (HDSR) documents, enhancement and bug fixing
    • QAC, static code analysis, technical reference manual mapping to code
    • Analyzed graphics performance issue
    • Security policy for cyber security requirements
    • Integration & testing of applications

Impact:

Sasken successfully developed the applications for the instrument cluster and reduced customer’s time-to-market by 30%.
