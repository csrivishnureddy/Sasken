Remote Monitoring & Control of Precision Welding

Written by Admin | Dec 17, 2019 5:00:00 AM

Scope: Customer‘s conventional welder was facing high downtime, therefore, they wanted to upgrade it to a next-gen welder with connectivity and remote monitoring to reduce downtime.

Solution:

Sasken was responsible for the end-to-end software development of the customer’s Industry 4.0-ready welder with an electro-mechanical advanced actuation system that provides unprecedented control and position accuracy.

  • BLE/ Wi-Fi module: Design and develop Reference Setup of BLE/ Wi-Fi module
  • Wi-Fi Middleware: Develop, integrate and test Wi-Fi Middleware on TI Sitara system
  • BLE Middleware: Develop, integrate and test BLE Middleware and BLE Data Handler on TI Sitara system
  • Data Sets: Create profile to transfer data and profiles with attributes to transfer different data sets
  • Test Applications: Develop and integrate Test Applications to establish communication between VxWorks 7.0 & devices
  • Communicate with Data Handler for BLE module

Impact:

  • Enabled customer to develop an Industry 4.0/IIoT-enabled welding machine, providing access to actionable performance, diagnostic data, supporting production efficiency and traceability
  • Better visibility into system KPIs through real-time remote monitoring
  • Better controllability as a result of enablement of remote configuration of machine KPIs
  • Enabled better maintenance owing to lower time for issue resolution by service engineers
